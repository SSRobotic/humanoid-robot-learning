## 🚀 Start here

1. Choose a task and a training framework that already supports your robot or simulator.
2. Review observation / action spaces, reward definitions and dataset provenance.
3. Reproduce the upstream training example and record versions before changing the task.

Read the [engineering guide](GUIDE.md) for a practical selection checklist. [resources.json](resources.json) contains the structured entries.
